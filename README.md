# EcoBuddy

EcoBuddy is a web application that estimates a user's carbon footprint based on daily lifestyle choices and provides personalized sustainability recommendations.

## Features

- Carbon footprint assessment based on user inputs
- Personalized sustainability recommendations
- Environmental impact summary
- Report generation and display
- Assessment history with saved reports
- Timestamped records stored in a SQLite database

## Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Python
- Flask

**Database**
- SQLite

## Installation

```bash
git clone <repository-url>
cd EcoBuddy
pip install -r requirements.txt
python app.py
```

Open the application at:

```text
http://127.0.0.1:5000/
```
